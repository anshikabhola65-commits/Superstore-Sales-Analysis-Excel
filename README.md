### Superstore Sales Analysis Using Excel

**Project Overview**  
Analysed Superstore sales data using Microsoft Excel to understand sales performance, profitability, and customer segments.

**Tools Used:** Microsoft Excel, PivotTables, Charts, Excel Dashboard

**Key Features**
- Created PivotTables to summarise sales and profit by category and region.
- Analysed profit across different product categories.
- Compared sales across customer segments.
- Designed an interactive-looking dashboard displaying key performance indicators (KPIs) and charts.

**Key Metrics**
- Total Sales: 2,297,200.86
- Total Profit: 286,397.02
- Product Categories: 3
- Regions: 4

**Objective**  
To present sales data in a clear visual format and identify differences in sales and profitability across categories, regions, and customer segments.
